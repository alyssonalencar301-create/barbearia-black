# Barbearia Black — protótipo

## Como usar
1. Extraia os arquivos.
2. Abra `index.html` no navegador.
3. Faça um agendamento para testar.
4. O botão **Agenda** abre o painel administrativo.
5. Os agendamentos ficam salvos no `localStorage` do navegador.

## Próxima etapa
Para transformar em um sistema real para vários clientes/dispositivos, precisamos trocar o `localStorage` por um banco de dados online (ex.: Supabase) e publicar o site.
